# Superseded pre-release API v2 proposal

This document preserves the name of the unimplemented API v2 proposal accepted
by TASK-189. On 2026-08-13, before any `/api/v2` route, client, migration, or
deployment was created, the owner replaced that proposal with one versioned
integration API at `/api/v1` and current hypermedia JSON representations on
selected unversioned human document paths.

No `/api/v2` route is planned or implemented. The current living design is
[Hypermedia and integration API](hypermedia.md). TASK-189's acceptance record
and CHANGELOG entry remain historical evidence of the earlier planning choice;
they do not describe a shipped interface.
